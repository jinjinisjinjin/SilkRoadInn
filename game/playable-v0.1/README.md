# 《丝路食肆》正式试玩原型 v0.2

本地网页原型，用于验证「经营订单 -> 获得铜钱 -> 前置解锁 -> 九项场景修缮 -> 完成回传与奖励 -> 返回流沙驿」的完整闭环。

## 当前可玩闭环

1. 新档从小石磨、炉饼订单、0 枚铜钱和满额 100 驼铃开始；先经营赚铜钱，再逐块修缮。
2. 完成第一单后，按既定顺序修缮 22 个点位；每个点位都有独立的铜钱消耗与剧情文本，不要求指定订单。
3. 每一处只有逐块施工所需的费用，没有累计赚取铜钱的关卡目标。能支付当前修缮部位后可以进入场景；铜钱不足时，对应部位会明确显示还差多少，已完成的部位与余额会保留。继续完成任意可接订单即可攒钱推进。
4. 进入后是纯全屏修缮场景：直接点真实破损、单指拖拽、双指缩放；没有数字、任务卡、页头、按钮、热点框或三选一。
5. 最后一类破损完成后才显示完成文案；点击文案淡出，父页结算奖励、写入剧情状态并返回流沙驿。
6. 测试模式可通过“重置原型进度”清除本地存档，回到新档。

## 成长流程测试

开发模式的行囊底部可以一键切换新档、20单、60单、120单、190单和260单状态。每个状态使用独立测试存档，不会覆盖正式试玩进度；切换时会重新建立与该阶段对应的生成器、订单、礼包、铜钱和修缮状态。

生成器遵循固定的两两合成规则：八份同系初阶材料依次合成四份进阶、两份成型材料，再合成一台Lv1生成器；两台同类、同等级生成器可升到下一级，最高Lv6。每条生产线完成4、10、18、30单时依次把Lv1至Lv4副本放入奖励行囊；达到48单并完成大师订单后放入Lv5副本，由玩家自行取出。驿站修缮只负责解锁新的生产线，不拦截已经凑齐的生成器合成。新档赠送的小石磨是开局教学所需的唯一初始例外。

棋盘右上角提供圆形手动产出倍率按钮，点击后按 `×1 → ×2 → ×4 → ×1` 循环切换。点击手动生成器时，三种模式分别消耗 `1 / 2 / 4` 倍驼铃，并直接产出该生产线的一级、二级或四级食品；当前选择写入存档。奶房等自动生成器继续使用自身的库存、冷却和概率规则，不受手动倍率影响。

顶部宝袋入口会打开铺面式的“驿站小铺”。九格木货架目前陈列西域晨礼宝袋、聚财陶俑和梭梭树，并预留六个后续商品位；玩家每天可免费领取一份宝袋，也可用红宝石购买每16小时刷新的固定好物。购得道具进入奖励行囊，放到棋盘后可逐枚产出不同等级的铜币或驼铃棋子。可用 `?qa=daily-shop-v1&reset=1` 直接预览。

整条合成线可用 `?mode=release&qa=generator-chain-v1&category=mill&reset=1` 独立试玩。页面提供六条生产线切换和明确标注的同级副本测试按钮。奶房生成器合成完成后立即向四周投放食物；测试按钮会清理当前生产线的食材并补一台同级副本，让玩家继续检验升级。清理只在独立试玩中发生，不影响正式存档。

奶房是自动生成器，每轮库存随等级依次为 `6 / 10 / 14 / 18 / 22 / 26` 份。食物只会投放到奶房周边八格；周边放满时，未投放的库存会保留，等玩家腾出周边空格或把奶房移到新的空位后继续投放。整轮库存投完后才开始一小时补货。Lv1只产鲜乳，Lv2至Lv6直接产出乳糜的概率依次为 `8% / 14% / 20% / 26% / 32%`，其余仍为鲜乳。

每日宝袋放到棋盘后，会按间隔逐枚吐出铜币和体力棋子；棋盘满时暂停，腾出格子后再次点击继续，已经抽定的奖励会随存档保留。体力棋子依次表现为一枚驼铃、两枚驼铃、单峰驼和成熟双峰驼，数值为 `2 / 8 / 30 / 100`；两枚同级可以继续合成，任一级都能双击收获体力。

## 已接入的四卷主线

- Lv1「流沙驿初明」：02 前厅客座、04 后厨灶间、11 食单上墙。
- Lv2「西市烟火」：03、05、06、15、16、17-18。
- Lv3「楼馆通途」：07、08、09、10、12、13-14。
- Lv4「灯火连城」：19、20、21-23、24、25、26、27。

共 22 个唯一玩家点位。每个里程碑均记录 `chapter`、`playerPointId`、`playerUrl` 与 `longscrollRegionIds`；开局完成一单后，修完前一处并有足够铜钱支付下一部位即可继续修缮，跨章时还需先完成驿站扩建。每章通关只发放一个礼匣，礼匣内的铜钱、驼铃和材料在打开时领取，不再额外结算驼铃或红宝石。已有的 Lv1 三点也已采用同一长卷区域字段，供长卷视觉层统一读取。

## 验收结果

- 桌面端已逐条跑通 Lv2-Lv4：扣费、九层完成、回传、奖励、剧情标记、后续解锁和 Lv4 最终完成状态均已验证。
- 铜钱不足会阻止当前部位施工，并显示“还差 X 铜钱”；退出后可以继续经营，再回到同一进度续修。
- 测试模式的重置操作已验证会删除本地存档并回到新档。
- 手机尺寸 `390 x 844`：玩家页保持纯全屏场景；真实鼠标拖拽与滚轮缩放已验证，控制台为 0 errors、0 warnings。双指缩放逻辑与单指使用同一相机状态机。
- 玩家页嵌入时从 `repairId` 读取当前点位，完成后向父页发送 `silkroad:repair-complete`；重新进入未完成点位不会重复扣费。

## 长卷状态约定

正式试玩已写入统一的区域与剧情状态，但正式长卷的“旧层/完成底图”视觉渲染仍由长卷模块依据 `longscrollRegionIds` 与已修缮状态接线。当前流沙驿内景只用四个临时锚位承载入口，不应把它视为最终长卷视觉。
