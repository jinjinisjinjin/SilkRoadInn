# 《丝路食肆》玩法逻辑定稿 v0.1

版本：v0.1
阶段：Lv1 MVP
目标：锁定第一阶段核心玩法，作为后续UI、数值、开发原型的依据。

## 1. 玩法定位

《丝路食肆》第一阶段是低压力、轻经营、图鉴收集驱动的合成经营小游戏。

核心不是战斗、竞技或强倒计时，而是：

- 合成食物的连续爽感。
- 完成旅人订单的明确目标。
- 修复《丝路食单》的收集满足。
- 一点点修缮流沙驿的成长感。

## 2. 核心循环

```text
驼铃自然恢复
-> 点击「迎客」
-> 消耗1点驼铃生成食材
-> 食材进入7x9案板棋盘
-> 拖拽两个相同物品合成更高级物品
-> 完成NPC订单
-> 获得铜币 / 食单经验 / 图鉴解锁
-> 修缮流沙驿
-> 提升驼铃上限、恢复速度、后续解锁新产品线
```

一句话规则：

> 点迎客拿食材，在案板上二合一，做出旅人要的食物，补全祖辈留下的《丝路食单》。

## 3. 第一阶段范围

| 模块 | Lv1 MVP定稿 |
|---|---|
| 场景 | Lv1「流沙驿」后厨 |
| 棋盘 | 开局即7x9 |
| 合成线 | 胡饼8级 |
| 体力 | 驼铃 |
| 订单 | 顶部3个NPC订单 |
| 图鉴 | 胡饼线8张图鉴 |
| 成长 | Lv1后厨小修、Lv2预告 |
| 存档 | 微信本地Storage |

MVP暂不做：

- 棋盘内复杂生成器。
- 多产品线同时开放。
- 限时失败惩罚。
- 强排行榜。
- Supabase云存档。
- 大型壁画展览馆。

## 4. 棋盘规则

| 项目 | 规则 |
|---|---|
| 开局尺寸 | 从新手教学开始即使用7x9，共63格 |
| Lv1正式尺寸 | 维持7x9，共63格 |
| 操作 | 拖拽两个相同物品重叠合成 |
| 合成 | 2个同级物品 = 1个下一级物品 |
| 目标格 | 合成结果出现在拖拽目标格 |
| 源格 | 被拖拽物品原格清空 |
| 不同物品 | 拖拽失败，物品回弹 |
| 满格 | 无空格时「迎客」置灰，不消耗驼铃 |
| 高阶保护 | 5级及以上物品出售/丢弃需二次确认 |

设计结论：

- 7x9是Lv1正式体验，兼顾合成空间和手机可读性。
- Lv2不再向更小棋盘变化；若需要成长感，优先考虑额外储物格或高级生成器，而不是改小棋盘。

## 5. 生成规则

生成入口：

- 底部主按钮「迎客」。
- 每次点击消耗1点驼铃。
- 生成1个食材，自动放入棋盘空格。

放置规则：

1. 优先放入玩家最近操作区域附近的空格。
2. 若无法判断，按从下到上、从左到右寻找空格。
3. 棋盘满格时不可生成。

生成概率：

| 玩家进度 | 麦面剂 | 炉饼 | 胡麻饼 |
|---|---:|---:|---:|
| 新手前10次 | 100% | 0% | 0% |
| 解锁胡麻饼后 | 90% | 10% | 0% |
| 解锁油胡饼后 | 82% | 15% | 3% |
| 完成8单后 | 75% | 20% | 5% |

说明：

- MVP不做棋盘内生成器，避免第一版过复杂。
- 后续可在Lv2加入“麦袋/食篮”作为棋盘内生成器。

## 6. 驼铃体力

驼铃是世界观化体力：远处商队经过，驼铃声带来新的食材。

| 项目 | 数值 |
|---|---:|
| 初始上限 | 24 |
| 自然恢复 | 每6分钟+1 |
| 首次进入赠送 | +18 |
| 每日首次登录 | +12，不超过上限 |
| 单次迎客消耗 | 1 |
| 广告补给 | 每日3次，每次+8 |
| 铜币补给 | 每日2次，80/160铜币各买6点 |
| 小修后上限 | 30 |
| 小修后恢复 | 每5分钟+1 |

文案口径：

- 不显示“体力”二字，统一称为“驼铃”。
- 恢复提示用“远处又传来驼铃声”。

## 8. 订单系统

主界面同时显示 2–7 个订单。已到访且未交付的订单持续保留，直到玩家交付。

订单字段：

- NPC头像。
- NPC名称。
- 需求物品与数量。
- 奖励铜币。
- 交付按钮。

交付规则：

1. 棋盘内拥有足够物品时，订单按钮亮起。
2. 点击「交付」自动扣除对应物品。
3. 发放铜币和食单经验。
4. NPC说一句短台词。
5. 交付后从当前可制作的订单池补入新订单。

保留与补单规则：

| 项目 | 规则 |
|---|---|
| 未完成订单 | 不定时替换，持续保留至交付 |
| 交付补位 | 交付后按当前可制作范围补入新订单 |
| 订单刷新 | 不提供自动、免费或铜币刷新 |
| 稀有订单 | 解锁髓饼后出现神秘胡商订单 |
| 压轴订单 | 解锁古楼子前后触发商队首领订单 |

## 9. 图鉴系统

图鉴名称：《丝路食单》。

触发：

- 玩家首次合成新物品。

弹窗结构：

```text
收入《丝路食单》
胡麻饼
饼面撒胡麻，一口尝到西域风。
[知道了] [查看食单]
```

详情页字段：

| 字段 | 说明 |
|---|---|
| 古名/策划名 | 例如胡麻饼 |
| 现代理解 | 芝麻烤饼 |
| 一句话冷知识 | 合成瞬间弹出 |
| 完整图鉴文案 | 120-180字 |
| 考据可信度 | 内部字段，玩家可不显示 |
| 出处备注 | 后续补正式文献来源 |

原则：

- 轻弹窗不打断操作。
- 长考据放进图鉴详情。
- 存疑内容不写死为敦煌文书记载。

## 10. 堵格与整理

必须有低压力清格手段。

MVP规则：

| 功能 | 规则 |
|---|---|
| 出售 | 长按物品出现「出售」 |
| 出售收益 | Lv1-Lv3给少量铜币；Lv4以上需确认 |
| 行囊 | 底部入口，柜中提供8个免费仓位 |
| 邀请开仓 | 每成功邀请1位新掌柜，免费解锁1个仓位；平台邀请与成功追踪尚未接入 |
| 满格提示 | “案板已满，先合成或收起一些食材吧。” |
| 高阶保护 | Lv5以上出售二次确认 |

行囊建议：

- 当前提供8个免费仓位。
- 只能存放食物，不能存订单。
- 后续仓位可使用红宝石逐格开启，或每成功邀请1位新掌柜免费开启1格。邀请成功追踪待平台能力接入。

## 11. 新手流程

| 步骤 | 目标 | 操作 |
|---|---|---|
| 1 | 认识驼铃 | 点击迎客，生成麦面剂 |
| 2 | 认识合成 | 合成炉饼 |
| 3 | 认识订单 | 交付炉饼给沙州驿卒 |
| 4 | 认识图鉴 | 炉饼收入《丝路食单》 |
| 5 | 认识棋盘扩建 | 完成3单后提示案板可修宽 |
| 6 | 进入正式棋盘 | 棋盘保持7x9 |

原则：

- 每步只教一个动作。
- 主角女掌柜负责引导。
- 不连续弹长篇说明。

## 12. Lv1成长目标

| 阶段 | 条件 | 奖励 |
|---|---|---|
| 教学完成 | 完成3单 | 棋盘保持7x9 |
| 小修后厨 | 完成8单，累计200铜币 | 驼铃上限30，恢复改为5分钟 |
| 食单初成 | 解锁6张图鉴 | 神秘胡商订单出现 |
| Lv1完成 | 解锁8张图鉴，完成20单，交付古楼子 | Lv2「敦煌食肆」预告 |

Lv1完成文案：

```text
流沙驿的炉火，终于重新亮给远行人看了。
风从沙丘那边来，带着更远处的驼铃声。
```

## 13. UI与页面确认

当前主界面结构：

```text
顶部：Logo / 资源栏 / 3个紧凑订单
中部：7x9案板棋盘
下部：选中物品短句 / 掌柜教学气泡
底部：食单 / 迎客 / 驿站 / 行囊
```

规则：

- 主棋盘是视觉中心。
- 主角掌柜不长期占据大面积，只在教学、剧情、图鉴演出中出现。
- 字体采用原创敦煌木牌/写经感标题方向，正文保证清晰，不仿竞品字体。
