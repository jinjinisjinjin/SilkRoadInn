## 当前产品决策

1. 取消“三选一装修”路线。
2. 唯一完成风格固定为“暖沙烟火”。
3. 修缮流程改为：剧情/金币解锁点位 -> 进入未修缮内景 -> 点击旧物件/旧区域 -> 展示修缮消耗与状态 -> 修好后在原位替换为暖沙烟火完成层。
4. 后续所有可替换素材都应来自同一个点位的“暖沙烟火完成图”，不能混用其他点位或其他风格。
5. 技术上优先采用“旧底图 + 分层 PNG 覆盖”的方式；环境色、地面、墙面这类大范围变化用大遮罩层或阶段整图过渡处理。

## “对应暖沙烟火完成图路径”的意思

“对应暖沙烟火完成图路径”指的是：每个未修缮点位要拿来切图的最终修好版本原图。
例如“门楼”修缮时，旧图作为底图，完成图 `/Users/zhuangjin/Documents/Codex/SilkRoadInn/art/interiors/lv1/repaired/门楼_暖沙烟火翻修_v0.1.png` 就是后续切出新门帘、新灯、新门框、新地面光影的来源。

## 总体核验结论

1. Lv1-Lv2：大多数点位机位稳定，适合直接走“旧图底图 + 局部完成层”的切割方案。
2. Lv3：多数点位也能对位；其中“13+14 望楼通途”的整体光照和装饰变化较大，建议增加一个环境过渡层。
3. Lv4：整体最适合切层，因为旧图与完成图的构图非常接近；但“25 东棚盈市”和“27 灯火连城”的暖光氛围变化很强，建议把灯光/墙面暖色单独作为大层。
4. 地板、墙面、天空、整体色温不建议切成太碎的小块；更适合做成“环境修缮层”，在关键剧情节点整体淡入。
5. 每个点位建议先做 5-8 个可修缮层，优先覆盖画面中上中下、左中右都有内容的位置，避免玩家觉得只修了一个角落。

## 后续执行顺序

1. 先选一个点位做试切，建议从 `01 门楼` 或 `20 中市开席` 开始。
2. 在旧图上标出 5-8 个可修缮区域。
3. 从对应暖沙烟火完成图中切出同位置透明 PNG。
4. 做一个本地点位预览：旧底图上逐层开关，检查是否对位、是否边缘突兀。
5. 用户确认后，再批量推进同等级其他点位。

## 不建议的做法

1. 不建议再画三套风格图。现在风格已经统一，继续三选一会增加美术量，也会稀释“暖沙烟火”的主线感。
2. 不建议只切小物件。地面、墙面、灯光、棚布这类大面积变化才是“修好了”的主要反馈。
3. 不建议让所有点位同时变亮。应该按剧情阶段逐点激活，否则玩家看不到修缮推进感。
4. 不建议把完成图直接整张替换掉旧图，除非旧图和完成图机位不一致；整张替换会让修缮过程缺少“亲手一点点变好”的感觉。
