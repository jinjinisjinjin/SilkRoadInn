# 《丝路食肆》视觉方向板 v0.1

用途：统一后续场景、食物图标、NPC、UI与宣传素材的视觉标准。

## 1. 视觉总纲

一句话方向：

**明亮、温润、可玩的敦煌壁画绘本风。**

这不是厚重博物馆展陈，也不是普通古风手游。画面要保留敦煌矿物色、铁线描、戈壁黄昏和丝路旅人的文化气质，但整体明度要适合微信小游戏长期游玩。

核心气质：

| 关键词 | 解释 |
|---|---|
| 明亮 | 主界面不能太暗，手机屏幕上要清楚 |
| 温润 | 像纸本岩彩绘本，不要冷硬3D |
| 克制 | 不堆仙侠光效、不滥用金光 |
| 可读 | 棋盘、订单、按钮优先清楚 |
| 考据感 | 食材、人物、器物尽量符合晚唐沙州敦煌语境 |

## 2. 基准素材

### 主场景基准

采用明亮版「Lv1流沙驿后厨」作为主界面方向。

![Lv1流沙驿后厨明亮版](./丝路食肆_视觉探索02_Lv1流沙驿后厨_明亮版.png)

使用判断：

- 适合主界面：明度够，案板区域清楚，能叠7x9棋盘。
- 保留点：土坯墙、木案板、炉火、石磨、麦袋、门外沙丘与商队。
- 后续优化：墙面人物与纹样压低对比，避免抢UI焦点。

### 食物图标基准

采用胡饼8级图标合辑 v2 作为合成物方向。

![胡饼8级图标合辑v2](./丝路食肆_视觉探索04_胡饼8级图标合辑_v2.png)

使用判断：

- 等级递进成立。
- 第3「胡麻饼」和第4「油胡饼」已通过轮廓与材质拉开。
- 后续还可继续增强铁线描和平涂感，减少水彩食物插画感。

### NPC基准

采用 NPC v2 作为人物比例与风格方向。

![NPC粟特胡商与求法僧人v2](./丝路食肆_视觉探索06_NPC粟特胡商与求法僧人_v2.png)

使用判断：

- 人物不是Q版，符合半写实比例。
- 粟特胡商保留异域识别度。
- 求法僧人更接近汉地清俊审美。
- 后续人物需更生活化，避免过度舞台化和奇观化。

## 3. 色彩板

| 色彩 | 用途 | 气质 |
|---|---|---|
| 沙土黄 | 主背景、墙面、纸张 | 明亮、温暖、耐看 |
| 赭石 | 木器、墙面阴影、饼食暗部 | 敦煌感、古朴 |
| 石青 | 次级按钮、冷色装饰 | 平衡暖色 |
| 石绿 | 葱、植物纹样、状态点缀 | 生机、丝路风 |
| 朱砂红 | 印章、重要提示、少量订单强调 | 文化感、焦点 |
| 暗鎏金 | 铜币、稀有边框、主按钮描边 | 奖励感 |
| 烟墨黑 | 线条、正文文字 | 铁线描、可读性 |

色彩原则：

- 主界面整体明度要高于第一版暗场景。
- 暖色为底，石青石绿做平衡。
- 金色只做奖励和边框，不铺满。
- 红色少量使用，避免喜庆化或网红化。

## 4. 场景规范

Lv1「流沙驿」后厨应包含：

| 元素 | 作用 |
|---|---|
| 木案板 | 放置合成棋盘，必须清爽 |
| 土坯墙 | 建立敦煌边城质感 |
| 土灶炉火 | 温暖生活感 |
| 石磨 | 麦面食物链合理性 |
| 麦袋、胡麻袋 | 胡饼线来源 |
| 蒜辫、葱束、风干肉条 | 后厨细节 |
| 酱瓮、陶碗、木勺 | 古代厨房器物 |
| 低对比壁画纹样 | 敦煌识别，但不能抢UI |
| 门外沙丘与商队 | 丝路空间感 |

不可出现：

- 辣椒、番茄、土豆、玉米。
- 不锈钢、玻璃瓶、塑料筐。
- 现代灯箱招牌。
- 赛博霓虹、仙侠强光。

## 5. 食物图标规范

食物图标必须优先服务合成玩法。

核心规则：

| 规则 | 说明 |
|---|---|
| 小图优先 | 64px下仍能区分 |
| 相邻等级不能太像 | 不只靠颜色深浅区分 |
| 每级有主识别点 | 轮廓、切面、配料、容器、加工状态至少一个明显变化 |
| 轮廓优先 | 相邻等级相似时，先改轮廓，再加细节 |
| 少用真实摄影感 | 不做外卖App食物图 |

胡饼线已确认的识别方案：

| 等级 | 主识别点 |
|---:|---|
| 1 麦面剂 | 未烤面团、柔软褶皱 |
| 2 炉饼 | 素烤圆饼、焦斑 |
| 3 胡麻饼 | 密集黑白胡麻、干爽薄圆饼 |
| 4 油胡饼 | 油酥折边、分层裂纹、少量油光 |
| 5 葱豉胡饼 | 葱绿与深色豉汁 |
| 6 羊肉胡饼 | 切口露羊肉馅 |
| 7 髓饼 | 厚重、蜜油光泽、温润深金 |
| 8 古楼子 | 层叠切面、宴席级复杂度 |

## 6. 人物规范

总体：

- 唐风半写实比例。
- 禁止Q版大头、幼态萌系、现代网红脸。
- 角色要像真实会进入驿站吃饭的旅人，不像抽卡立绘。

主角掌柜：

- 默认设定为20岁出头的沙州本地汉人女掌柜。
- 气质温和、清醒、能干，有烟火气和书卷气。
- 服饰为适合经营后厨的唐风日常衣装，不穿华丽宫装。
- 主要用于新手引导、图鉴解锁、剧情、启动页和宣传图，不长期占据主棋盘空间。

面部规则：

| 人群 | 五官方向 |
|---|---|
| 汉人、沙州本地人、长安使者 | 清俊端正、汉地审美 |
| 求法僧人 | 可偏汉地清俊，温和、清瘦、克制 |
| 粟特胡商 | 深目高鼻、胡须、商旅气 |
| 波斯艺人、大食商人 | 可有异域识别，但不能夸张奇观化 |
| 回鹘牧民 | 草原感、结实、风尘感 |

汉地清俊方向：

- 清瘦脸型。
- 直眉。
- 鼻梁干净。
- 唇形克制。
- 眼神温和。
- 清朗端正的青年气质。
- 不仿任何具体真人或明星可识别长相。

## 7. UI方向

界面应像“可以操作的驿站后厨”，而不是一张盖满装饰的古画。

| UI元素 | 方向 |
|---|---|
| 顶部资源栏 | 铜币、驼铃、食单进度，浅底深字 |
| 棋盘 | 木案板上的稳定网格；开局与Lv1正式均采用7x9 |
| 订单 | 木牌或纸签，压缩为紧凑信息条，不要厚卡套卡 |
| 主按钮 | 铜铃图标 +「迎客」 |
| 图鉴 | 古卷纸底，短句优先，长文收起 |

按钮圆角不超过8px。图标优先使用世界观内物件：铜铃、卷轴、铜币、木牌、食篮。

字体方向：

- Logo和主要标题使用原创定制字形方向，参考敦煌写经、唐代木牌刻字和古卷题签气质。
- 不照抄任何竞品或现成游戏字体。
- UI正文必须清楚易读，避免纯书法导致按钮和订单难辨。
