# 《丝路食肆》开发数据配置 v0.1

这组文件把玩法定稿拆成可开发的数据表，方便后续快速搭原型。

## 文件说明

| 文件 | 用途 |
|---|---|
| `items.json` | 胡饼8级物品、合成关系、售价、图鉴绑定 |
| `orders.json` | NPC订单池、需求、奖励、权重、解锁条件 |
| `codex.json` | 《丝路食单》图鉴短句、长文、可信度 |
| `stamina.json` | 驼铃体力、恢复、补给、生成概率 |
| `progression.json` | 棋盘尺寸、行囊、Lv1里程碑 |

## 使用原则

1. 原型代码优先读取配置，不把数值写死在逻辑里。
2. 美术资源通过 `iconKey` 对应，不直接在配置里绑定具体文件路径。
3. 文案可以继续改，但字段结构尽量稳定。
4. 考据可信度是内部字段，玩家界面不一定显示。
5. v0.1只覆盖胡饼线和Lv1，后续产品线按同样结构扩展。
