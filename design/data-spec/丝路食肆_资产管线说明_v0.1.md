# 《丝路食肆》资产管线说明 v0.1

## 目标

减少“画图 -> 裁图 -> 命名 -> 接原型 -> 验证”的重复劳动。后续新增同类资源时，优先改 `资产管线_manifest_v0.1.json`，再运行统一脚本批量生成。

## 核心文件

| 文件 | 用途 |
|---|---|
| `资产管线_manifest_v0.1.json` | 记录所有可接入资产的来源、裁切区域、输出路径和状态 |
| `work/build_assets_from_manifest.py` | 按manifest批量复制/裁切/缩放/圆角处理 |
| `outputs/丝路食肆_可玩原型_v0.1/assets/` | 原型实际读取的资源目录 |

## 资产状态

| 状态 | 含义 |
|---|---|
| concept | 仅概念探索，不接原型 |
| selected | 方向确认，等待裁切或接入 |
| cropped | 已生成独立资源 |
| wired | 已接入原型或配置 |
| approved | 用户确认可作为当前基准 |

## 新增资产流程

1. 生成或导入概念图。
2. 在manifest中新增条目，填写 `id/type/source/output/mode`。
3. 若需裁切，填写 `crop` 或 `grid`。
4. 运行：

```bash
python3 work/build_assets_from_manifest.py
```

5. 原型按ID自动读取资源，例如：

```text
assets/npc/{npcId}.png
assets/{iconKey}.png
```

## 原则

- 不再为每张图单独写一次裁切脚本。
- 同一类资产一批处理，一批接入。
- 代码读取稳定ID，不读取概念图文件名。
- 还没定稿的图不要急着接进原型。
